# UI documentation (source of truth)

Internal design documentation for the AID Edge ecosystem UI work. It lives on this dedicated branch
(`docs/ui-source-of-truth`) so it is never part of the published site tree on `main` or `ui/foundation-audit`.
Do not merge this branch into a branch that is deployed.

- `papers/BRIEF.md` - the UI brief (authoritative design values, copy rules, events table)
- `papers/AUDIT.md` - Papers audit: current value to target token, hard-coded values, recommendations
- `shots-prompt2/` - footer and button screenshots from the foundation pass (all sites)

Implementation of the Papers foundation is on branch `ui/foundation-audit` (`ui-tokens.css`, `ui-foundation.css`).
